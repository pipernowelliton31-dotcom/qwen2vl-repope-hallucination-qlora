01 · Central finding

这不是“微调后全面变好”，
而是一条可以被移动、也可以被突破的权衡曲线。

Attention QLoRA 提高 sensitivity，也放大 false-positive hallucination；数据分布能缓解它，视觉预算则在同一 adapter 上带来真正的双向纠错。

I

Calibration shift

Attention LoRA 让模型更愿意回答 “yes”。

E1 的 RePOPE Recall 升至 93.36%，但 FPR 同时升至 7.92%。收益主要来自减少 FN，代价是新增 FP。

II

Targeted supervision

改变负样本，比增加 LoRA 容量更有效。

E3 将 adversarial negatives 提高到 4,000 条，较 E1 把 FPR 从 7.92% 压到 5.66%；E2 几乎复制 E1，E4 也没有形成更优 frontier。

III

Discrimination gain

256→512 visual tokens 同时减少 FN 与 FP。

同一 E3 adapter 上，TP +39、FP −22；Yes Ratio 只变化 +0.21 pp，更符合视觉证据改善，而非单纯阈值漂移。

02 · Recall–FPR frontier

每一个点，都是一次错误分配。

向左意味着更少 hallucination，向上意味着更高 sensitivity。最理想的移动方向是左上；E3 的 256→512 是唯一在同一模型上明确向左上移动的消融。

RePOPE operating points

Base Formal Exploratory

横轴为 FPR（越低越好），纵轴为 Recall（越高越好）；虚线仅连接非支配点。

01

Fresh base 仍最保守

02

E3@512 是最佳综合点

Accuracy 93.39%、F1 92.29%，同时比 E3@256 少 61 个错误。

03

高 Recall 不是免费收益

E3/E4-2000 的 Recall 接近 94%，FPR 却升至约 9%。

四组实验都在 500、1000、1500、2000 steps 上评测。checkpoint-1000 往往更保守，后期模型重新走向高 Recall / 高 FPR。

05 · Calibration gap

Dev 排序有用，绝对 FPR 却过于乐观。

COCO-derived dev 基本保留了“谁更保守”的相对关系，但所有代表模型到了 RePOPE，FPR 都显著上升。这是跨数据集 calibration gap，而不是 dev 完全失效。

Dev 可以选 operating point，不能替代独立 benchmark。

08 · Experiment design

变量被拆开，结论才有解释力。

E1–E4 固定模型、量化、训练步数和 dev，仅改变 LoRA target 或负样本组成；RePOPE 不参与 checkpoint 选择。

E0

Fresh base

无 adapter；建立保守 operating point。

E1

Attention LoRA

q/k/v/o；Recall 上升，FPR inflation。

E2

+ Merger

E3

Hard negatives

adversarial negatives 2,666→4,000；正式模型。

+ MLP all-linear

10 · Boundaries

可以确认什么，仍不能声称什么。

可以确认

hard-negative supervision 能缓解基础 QLoRA 引入的 FPR inflation。

可以确认

E3@512 是已评测配置中 Accuracy 与 F1 最高的综合点。

不能声称

任何 fine-tuned 模型的 hallucination 已低于 fresh base。

不能声称

单个 256→512 消融已经证明内部机制是“看得更清楚”。

小规模 VLM 的核心限制，更可能来自 hard-example supervision、视觉信息充分性和跨数据集 calibration，而不是 LoRA 参数仍然不够多。
